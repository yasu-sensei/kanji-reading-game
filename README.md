# 漢字読み方ゲーム

小学1年生の漢字80字・400語の三択読み方ゲーム。宿題・練習モード、星、イラストガチャ、図鑑を開発予定。

- `docs/SPEC.md`: 確定仕様と変更履歴
- `data/kanji_400_final.csv`: 完成版400問の問題データ（改変禁止、変更時は履歴に記載）
- `images/`: 提供されたご褒美イラスト33枚と一覧（背景画像は未配置）
- `css/`, `js/`, `index.html`: 準備画面（80字の選択・解除とブラウザー内保存）

## 注意
児童の個人情報、学習記録、秘密鍵、暗証番号を公開リポジトリに入れないでください。

## 起動

追加パッケージやビルドは不要です。リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーでポート8000の `/` を開きます。選択は同じオリジンの localStorage に保存します。
共有ブラウザーでは選択も共有されます。児童別の管理方法は未確定です。
保存できない環境では通知し、画面内の選択は継続できます。

## ガチャ・図鑑（おためし）

`gacha.html` と `collection.html` を上記HTTPサーバーで開きます。準備画面のメニューからも移動できます。

- 提供イラスト33種類。それぞれ通常・ゴールド・レインボーの3段階で、最大99枚を収集します。
- 同じ種類の1枚目は通常、2枚目はゴールド、3枚目はレインボー。以前の見た目も図鑑に残ります。
- 3枚獲得済みの種類はガチャの対象から外し、99枚で終了。カード上の光はCSSで重ね、画像ファイルは変更しません。
- ガチャ機のハンドル／ボタンを押すと、ハンドル回転→カプセル排出→開封→カード表示の演出が進みます。演出中は両方の操作を無効化します。
- ゴールドは強い金色の反射と星のきらめき、レインボーは絵の上を流れる虹色の反射ときらめきを重ねます。
- おためしの星3個から開始し、1回1個消費。「おためしの星を3こふやす」で操作を確認できます。学習の星は付与・消費しません。
- 抽選はおためしとして残りの種類から等確率。本番の排出率やシークレット条件を確定するものではありません。
- おためし記録は `kanji-reading-game:rewards-demo:v1` のlocalStorageに保存。準備画面の保存とは独立しています。児童別の保存やサーバー保存は未連携です。
- 図鑑は3段階のフィルター、所持のみ表示、獲得済みカードの拡大に対応。動きを減らす設定では光のアニメーションを停止します。
- 保存が壊れている／保存できない場合は通知し抽選を停止。リセットは「おとなの方へ」から確認後におためし記録だけを削除します。

動作確認（Playwright・Chromium導入済み、HTTPサーバー起動後）:

```sh
node tests/rewards.cjs
node tests/gacha-animation.cjs
node tests/preparation.cjs
```

## よみかた10問（おためし）

準備画面で漢字を1字以上選び、「よみかた10もんをはじめる」を押します。
`quiz.html` は選択をURLの `kanji` パラメーターで受け取り、パラメーターがない場合は準備画面の保存を参照します。
保存できないブラウザーでも、準備画面で選んだ漢字をURL経由で渡せます。

- 漢字選択の一覧はCSVの対象漢字が初めて登場する順です。
- 選択対象の問題だけで10問。1字の場合は5問を2回、2字以上の場合は重複なしで10問。
- おためしでは対象の問題・各問の選択肢を並べ替えます。習熟度の比率は未確定のため、本番の出題方式として確定していません。
- 1問につき最初の回答のみ判定し、タップ直後に問題文の下へ大きな○・×と正しい読みを表示してから手動で次へ進みます。
- 10問後に初回答の正解数と読みの一覧を表示。「同じ漢字でもう10問」で新しいセットを開始できます。
- この段階は操作確認用で、宿題・練習の判定、最大2周の復習、星の付与、学習記録の永続保存は未連携です。
- 解答と結果は画面内メモリーのみ。再読込・終了で失われます。ガチャのおためし記録や星は変更しません。
- Chromebookの横持ち・縦持ちを優先し、問題・選択肢・次へボタンを見やすく配置しています。

検証（HTTPサーバー起動後）:

```sh
python3 tests/validate_questions.py
node tests/quiz.cjs
node tests/preparation.cjs
```

画像・CSVを埋め込んだオフライン確認用HTMLを、リポジトリ外に出力できます。

```sh
python3 scripts/build-preview.py /tmp/kanji-preview
```
