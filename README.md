# 漢字読み方ゲーム

小学1年生の漢字80字・400語の三択読み方ゲーム。宿題・練習モード、星、イラストガチャ、図鑑を開発予定。

- `docs/SPEC.md`: 確定仕様と変更履歴
- `data/kanji_400_final.csv`: 完成版400問の問題データ（改変禁止、変更時は履歴に記載）
- `images/`: 採用済みのガチャ景品・背景画像（原本は未配置）
- `css/`, `js/`, `index.html`: 準備画面（80字の選択・解除とブラウザー内保存）

## 注意
児童の個人情報、学習記録、秘密鍵、暗証番号を公開リポジトリに入れないでください。

## 起動

追加パッケージやビルドは不要です。リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーでポート8000の `/` を開きます。選択は同じオリジンの localStorage に保存します。
共有ブラウザーでは選択も共有されます。児童別の管理方法は未確定です。
保存できない環境では通知し、画面内の選択は継続できます。

## 今回の範囲と未配置ファイル

- 基本構成と準備画面のみ実装。宿題・練習・ガチャは次のタスクです。
- 提供CSVを `data/kanji_400_final.csv` に原本どおり配置しました。全400問に「要確認」が残っています。ユーザー承認により出題データとして使用できます。詳細は `data/README.md` を参照してください。
- 採用画像の原本も未配置です。`images/` に配置が必要です。画像は生成していません。
- 開発ルールは `AGENTS.md` を参照してください。

## 動作確認項目

80字が重複なく表示されること、タップ・キーボードで選択と解除ができること、
再読み込み後に選択・解除が復元されること、保存データの破損や保存禁止でも操作できること、
スマートフォン幅で横にはみ出さないことを確認します。

自動確認（Playwright と Chromium が導入済みの開発環境で、上記HTTPサーバーを起動して実行）:

```sh
node tests/preparation.cjs
```

Chromium の既定パスは `/usr/bin/chromium` です。別の場所なら `CHROMIUM_PATH` で指定します。
テスト用の新規ブラウザーで確認し、普段使うブラウザーの選択状態には触れません。
