# 提供された400問のCSV

`kanji_400_final.csv` はユーザー提供の `kanji_400_three_choices_updated_246.csv` とバイト単位で同一です。語彙・正答・誤答・確認状況は変更していません。
ユーザーは全400問に「要確認」表記が残る状態での出題利用を承認しています。表記は原本のままです。

- 問題番号1〜400は欠番・重複なし。
- 小学1年生の配当漢字80字×各5問。
- 各問は正答1つ・誤答2つ。必須欄に空欄なし、同一問題内の選択肢に重複なし。
- 246番は「花のたね」。
- 同じ語彙が異なる対象漢字に登録されている場合があるため、問題は語彙だけでなく固定の問題番号で識別します。

列: 番号、対象漢字、出題語彙、正しい読み、間違い①（候補）、間違い②（候補）、確認状況。

```sh
python3 tests/validate_questions.py
```

構造検証は読みの正しさや別解の不存在を保証するものではありません。
