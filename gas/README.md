# GASで配信する

1. https://script.google.com/ で「新しいプロジェクト」を作成。
2. 「コード.gs」に同梱のCode.gsの内容を貼り付け。
3. ＋ → HTMLを選び、名前を「Game」にしてGame.htmlの全内容を貼り付け、保存。
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
5. 実行ユーザーは「自分」。アクセスできるユーザーは学校の運用に合わせて選択（学校内の児童が利用できる設定）。
6. 「デプロイ」で表示される /exec のURLを児童に配布。

更新時: ファイルを差し替え、「デプロイを管理」→編集→バージョン「新バージョン」で更新。同じURLで配信する。

画像はGitHub PagesからHTTPSで読み込みます。学校のフィルターで画像ドメインも許可してください。
登録・問題・ガチャ・図鑑はGAS内の単一HTMLで切り替わります。CSVは内蔵し、外部取得しません。
保存はブラウザー内のlocalStorageです。GAS・スプレッドシートへの記録保存や端末間同期はありません。
GitHub PagesとGASでは保存元が違うため、既存の星・カードは自動で引き継がれません。
GASのプレビューではなく、デプロイ後の /exec URLで児童端末の保存・再読み込み・画像・ガチャを確認してください。
学校のGoogle管理設定によってウェブアプリ公開が制限される場合があります。

初回サービスは新しい学級・番号の登録時に星4個。再読み込みや同じ登録への戻りでは再付与しません。
端末内の登録なので、別端末やブラウザーデータ削除後の再登録では新規扱いです。

生成コマンド: python3 scripts/build-gas.py /tmp/kanji-gas
